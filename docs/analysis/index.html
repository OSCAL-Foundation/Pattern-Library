Analyses

Each analysis of an OSCAL question has a separate area, retained after conclusion to preserve the reasoning.

Analysis areas are never renamed, moved, or deleted. Concluded analyses are not rewritten to match later views. A replacement analysis receives a new area; the earlier analysis is marked as superseded to preserve the record.
