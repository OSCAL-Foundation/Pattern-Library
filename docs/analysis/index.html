Analyses

Each effort that debates a question about OSCAL gets its own area, and keeps it. An analysis is a record of what was weighed, so it is worth as much after it concludes as during.

An area is never renamed, never moved and never deleted, and a concluded one is not edited into agreement with a later view. When an effort is superseded the new one gets its own area and the old one is marked, so the record shows the change rather than replacing it.
