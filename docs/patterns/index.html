Summit, by Oscalate Systems

A model office system carried through all seven OSCAL models, from the controls it selects to the weaknesses it is still tracking. The models form one chain: a catalog defines the controls, a profile selects and tailors them, component definitions say how components implement them, the SSP documents the system, the assessment plan says how it will be checked, the results record what was found, and the POA&M tracks what is being fixed.

Two of the seven are published so far. The rest are named here with the rest of the chain rather than omitted, because which models an example is missing is part of what a reader needs to know about it.
