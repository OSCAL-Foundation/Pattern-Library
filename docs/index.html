OSCAL Foundation Pattern Library

There are few high-quality, representative examples of what an actual compliance package in OSCAL looks like, and few places where the arguments about how to build one are written down and kept. This library holds both.

Three areas, each with its own lifecycle. Patterns are the worked examples: complete artifacts a reader can open, not fragments. Analyses are the efforts that debate a question about OSCAL, one area per effort, kept after the effort ends so a later reader can see what was weighed. Recommendations are what an analysis produces when it reaches one.

An analysis is never edited into agreement with a later view and never deleted. When one is superseded, the new effort gets its own area and the old one is marked, so the record shows the change rather than hiding it.
